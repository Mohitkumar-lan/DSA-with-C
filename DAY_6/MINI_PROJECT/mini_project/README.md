# Search System

## Day 6 Mini Project

Search System is a C program that demonstrates two important searching algorithms:

1. Linear Search
2. Binary Search

---

## Features

- Takes a sorted array as input.
- Takes a target element.
- Searches using Linear Search.
- Searches using Binary Search.
- Displays the result.

---

## Concepts Used

- Arrays
- Functions
- Loops
- Linear Search
- Binary Search
- Time Complexity

---

## Complexity

### Linear Search

Time:

O(n)

Space:

O(1)

### Binary Search

Time:

O(log n)

Space:

O(1)

---

## Important

Binary Search requires a sorted array.

---

## Compile

gcc search_system.c -o search_system

---

## Run

search_system.exe

---

## Sample Input

7

10 20 30 40 50 60 70

50

---

## Expected Output

Linear Search: Found at index 4

Binary Search: Found at index 4
