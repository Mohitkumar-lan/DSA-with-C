# Student Rank Sorter

## Day 8 Mini Project

Student Rank Sorter is a C program that sorts student marks
from highest to lowest using Insertion Sort.

---

## Features

- Takes student marks as input.
- Sorts marks in descending order.
- Displays student ranking.
- Uses Insertion Sort.

---

## Concepts Used

- C Programming
- Arrays
- Functions
- Loops
- Insertion Sort
- Descending Order

---

## Algorithm

Insertion Sort

---

## Complexity

Best Case:

O(n)

Average Case:

O(n²)

Worst Case:

O(n²)

Space:

O(1)

---

## Sample Input

5

75 90 60 85 70

---

## Expected Output

Rank 1 -> Marks: 90
Rank 2 -> Marks: 85
Rank 3 -> Marks: 75
Rank 4 -> Marks: 70
Rank 5 -> Marks: 60

---

## Learning Outcome

This project helped me understand Insertion Sort,
shifting, descending order and ranking logic.
