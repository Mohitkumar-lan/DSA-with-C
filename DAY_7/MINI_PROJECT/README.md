# Student Marks Sorter

## Day 7 Mini Project

Student Marks Sorter is a C program that sorts student marks
using Bubble Sort.

---

## Features

- Takes marks as input.
- Displays original marks.
- Sorts marks in ascending order.
- Sorts marks in descending order.

---

## Concepts Used

- C Programming
- Arrays
- Functions
- Loops
- Bubble Sort
- Swapping

---

## Algorithm

Bubble Sort

---

## Complexity

Time Complexity:

O(n²)

Space Complexity:

O(n)

The program uses additional arrays to display both orders.

---

## Compile

gcc student_marks_sorter.c -o student_marks_sorter

---

## Run

student_marks_sorter.exe

---

## Sample Input

5

75 90 60 85 70

---

## Expected Output

Original Marks:
75 90 60 85 70

Ascending Order:
60 70 75 85 90

Descending Order:
90 85 75 70 60

---

## Learning Outcome

This project helped me understand Bubble Sort,
ascending order, descending order and array manipulation.
