# Student Marks Management System

## Day 1 Mini Project

This is a beginner-level C programming project created as part of my DSA with C Day 1 journey.

---

## Project Objective

The objective of this project is to create a simple student marks management system using basic C programming concepts.

---

## Features

The program can:

- Take student name
- Take roll number
- Take marks of five subjects
- Calculate total marks
- Calculate average
- Calculate percentage
- Display pass/fail result
- Display a formatted student report

---

## Concepts Used

- C programming
- Variables
- Data types
- Character arrays
- scanf()
- printf()
- Arithmetic operators
- Relational operators
- if-else
- Basic calculations

---
