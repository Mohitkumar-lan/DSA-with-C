# Day 1 — Interview Questions

## Q1. What is DSA?

Answer:
DSA stands for Data Structures and Algorithms. Data structures organize data, while algorithms provide steps to solve problems efficiently.

---

## Q2. What is a Data Structure?

Answer:
A data structure is a method of organizing and storing data so that it can be accessed and manipulated efficiently.

---

## Q3. What is an Algorithm?

Answer:
An algorithm is a finite sequence of well-defined steps used to solve a problem.

---

## Q4. Why is DSA important?

Answer:
DSA helps programmers organize data efficiently and solve computational problems efficiently.

---

## Q5. What is the difference between data and a data structure?

Answer:
Data is raw information or values, while a data structure is a method used to organize and manage that data.

---

## Q6. What is a linear data structure?

Answer:
A linear data structure stores elements sequentially. Examples include arrays, linked lists, stacks and queues.

---

## Q7. What is a non-linear data structure?

Answer:
A non-linear data structure organizes data in hierarchical or network-like relationships. Examples include trees and graphs.

---

## Q8. Give examples of linear data structures.

Answer:
Array, Linked List, Stack and Queue.

---

## Q9. Give examples of non-linear data structures.

Answer:
Tree and Graph.

---

## Q10. What is the difference between linear and non-linear data structures?

Answer:
Linear data structures organize elements sequentially, while non-linear data structures organize elements hierarchically or through complex relationships.

---

## Q11. What is C?

Answer:
C is a general-purpose procedural programming language used for system programming, embedded systems and application development.

---

## Q12. Why is C useful for learning DSA?

Answer:
C provides a strong understanding of memory, arrays, pointers, structures and dynamic memory allocation, which are important concepts in DSA.

---

## Q13. Where does execution of a C program begin?

Answer:
Execution normally begins from the main() function.

---

## Q14. What is printf()?

Answer:
printf() is a standard C library function used to display formatted output on the screen.

---

## Q15. What is scanf()?

Answer:
scanf() is a standard C library function used to take formatted input from the user.

---

## Q16. Why is & used with scanf()?

Answer:
The & operator provides the memory address of a variable to scanf(), allowing scanf() to store the input in that variable.

---

## Q17. What is a variable?

Answer:
A variable is a named memory location used to store a value.

---

## Q18. What is a data type?

Answer:
A data type specifies what type of value a variable can store.

---

## Q19. Name four basic C data types.

Answer:
int, float, double and char.

---

## Q20. What is type casting?

Answer:
Type casting is the conversion of a value from one data type to another.

---

## Q21. What is an operator?

Answer:
An operator is a symbol that performs an operation on one or more operands.

---

## Q22. What is the difference between = and ==?

Answer:
= is the assignment operator, while == is the equality comparison operator.

---

## Q23. What is the modulus operator?

Answer:
The % operator returns the remainder of an integer division.

Example:
10 % 3 = 1

---

## Q24. What are the characteristics of an algorithm?

Answer:
Important characteristics include input, output, definiteness, finiteness and effectiveness.

---

## Q25. What is the difference between a data structure and an algorithm?

Answer:
A data structure organizes and stores data, while an algorithm provides a sequence of steps to solve a problem.

---

## Q26. What are the main types of data structures?

Answer:
Data structures are broadly classified into linear and non-linear data structures.

---

## Q27. Is an array a linear data structure?

Answer:
Yes. An array is a linear data structure because its elements are arranged sequentially.

---

## Q28. Is a tree a linear data structure?

Answer:
No. A tree is a non-linear data structure because its elements are arranged hierarchically.

---

## Q29. What is an algorithm's finiteness?

Answer:
Finiteness means that an algorithm must terminate after a finite number of steps.

---

## Q30. What makes an algorithm effective?

Answer:
Its steps should be clear, practical and executable using available operations.
