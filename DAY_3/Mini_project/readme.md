# Student Marks Analyzer

## Day 3 Mini Project

This is a simple Student Marks Analyzer developed using C programming.

This project is part of my DSA with C learning journey.

---

## Objective

The objective of this project is to use arrays to store student marks and calculate useful statistics.

---

## Features

The program calculates:

- Total marks
- Average marks
- Highest marks
- Lowest marks

---

## Concepts Used

- Arrays
- Array traversal
- Loops
- User input
- Variables
- Conditions
- Maximum
- Minimum
- Average
- Type casting

---

## How It Works

1. The user enters the number of subjects.
2. Marks are stored in an array.
3. The array is traversed.
4. Total marks are calculated.
5. Maximum marks are found.
6. Minimum marks are found.
7. Average marks are calculated.
