# Array Analyzer

## Day 5 Mini Project

Array Analyzer is a C program that performs basic analysis on an integer array.

## Features

- Find minimum element
- Find maximum element
- Calculate array sum
- Find maximum subarray sum
- Display original array

## Concepts Used

- Arrays
- Loops
- Functions/logic
- Array Traversal
- Kadane's Algorithm
- Time Complexity

## Maximum Subarray

Kadane's Algorithm is used.

Time Complexity:

O(n)

Space Complexity:

O(1)

## Compile

gcc array_analyzer.c -o array_analyzer

## Run

array_analyzer.exe

## Sample Input

5

-2 3 -1 5 -4

## Expected Output

Minimum = -4

Maximum = 5

Sum = 1

Maximum Subarray Sum = 7

- Calculating sum
