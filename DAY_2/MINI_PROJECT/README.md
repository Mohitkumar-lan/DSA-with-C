# Simple Calculator

## Day 2 Mini Project

This is a simple calculator project developed using C programming.

The project is part of my DSA with C Day 2 learning journey.

---

## Objective

The objective is to create a calculator using:

- Functions
- switch
- if-else
- User input
- Arithmetic operators

---

## Features

The calculator supports:

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Exit option

---

## Concepts Used

- C Programming
- Functions
- Function parameters
- Return values
- switch statement
- if statement
- User input
- Arithmetic operators
- Conditional logic

---

## Functions Used

### add()

Performs addition.

### subtract()

Performs subtraction.

### multiply()

Performs multiplication.

### divide()

Performs division.
