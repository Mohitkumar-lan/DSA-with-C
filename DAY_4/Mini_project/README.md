# Student Marks Sorter

## Day 4 Mini Project

This project is a simple Student Marks Sorter developed using C.

The project demonstrates the use of arrays and sorting algorithms.

---

## Objective

The objective is to take marks of multiple students and arrange them in descending order to generate a simple ranking.

---

## Features

- Accept marks of multiple students
- Sort marks in descending order
- Display ranking
- Display highest marks
- Display lowest marks

---

## Concepts Used

- Arrays
- Functions
- Loops
- Conditions
- Bubble Sort
- Swapping
- Descending order
- Time Complexity

---

## Algorithm

The program uses Bubble Sort.

The largest values are moved toward the beginning by comparing adjacent elements and swapping them when required.

---

## Complexity

Time Complexity:

O(n²)

Space Complexity:

O(1)

---
