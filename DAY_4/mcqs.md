# Day 4 — Searching and Sorting MCQs

## Q1. What is searching?

A. Arranging data
B. Finding an element
C. Deleting data
D. Copying data

Answer: B

---

## Q2. Which search works on an unsorted array?

A. Binary Search
B. Linear Search
C. Both always
D. Neither

Answer: B

---

## Q3. Binary Search requires:

A. Unsorted data
B. Sorted data
C. Empty data
D. Only strings

Answer: B

---

## Q4. Worst-case complexity of Linear Search is:

A. O(1)
B. O(log n)
C. O(n)
D. O(n²)

Answer: C

---

## Q5. Worst-case complexity of Binary Search is:

A. O(n)
B. O(log n)
C. O(n²)
D. O(1)

Answer: B

---

## Q6. Binary Search divides the search space into:

A. 3 parts
B. 4 parts
